Marketing · Project 2

Customer Churn & Retention Intelligence

Problem

Subscription churn keeps rising despite marketing spend. Find behavioural churn patterns, segment at-risk customers, determine causes and generate personalised retention strategies.

Algorithm flow

InputProcessDecisionOutput
Load usage logs, billing, support tickets, tenure, plan data
Engineer features: login drop %, ticket count, payment failures, feature adoption
Label churned vs retained (historical window)
Train classifier (logistic / gradient boosting) → churn probability
Explain each score (top contributing features – SHAP-style)
Churn probability ≥ threshold ?
YES → cluster at-risk customers by dominant cause
LLM/rule engine maps cause → personalised retention offer
At-risk list + cause + action + expected saved revenue

Pseudocode

X = features(customers); y = churned_flag
model = GradientBoosting().fit(X_train, y_train)
for c in customers:
    c.p = model.predict_proba(c)
    c.drivers = top_k(shap_values(c), k=2)
at_risk = [c for c in customers if c.p >= THRESHOLD]
for c in at_risk:
    c.segment = cluster_label(c.drivers)           # e.g. 'Disengaged', 'Billing', 'Support'
    c.action  = PLAYBOOK[c.segment]                # or LLM(prompt=c.profile)
saved = sum(c.mrr * c.p * ACTION_SUCCESS[c.segment] for c in at_risk)
